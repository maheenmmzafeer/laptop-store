# 💻 Laptop Store

A modern and responsive laptop store web application built with Next.js, TypeScript and Tailwind CSS. The project focuses on clean UI design, reusable components, structured product layouts and smooth 3D animations for a more immersive experience.

---

## ✨ Features

- Modern and responsive UI design
- Product listing and showcase pages
- Reusable component architecture
- Clean navigation and layout structure
- Smooth 3D animated elements (UI enhancements)
- Fully responsive across devices

---

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

---

## 📁 Pages

- Home – Landing page with hero section and highlights
- Products – Laptop catalogue display
- About – Information about the store
- Contact – Simple contact form UI

---

## 🧠 Purpose

This project was built to practice modern frontend development, UI design systems and component-based architecture using Next.js.
